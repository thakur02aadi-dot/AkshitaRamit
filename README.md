# Akshita & Ramit – The Ring Ceremony 💍

A luxury interactive Indian Ring Ceremony invitation website for **Akshita Singh** and **Ramit Singh**, taking place on **23 November 2026** at **Chaudhary Farm House, Dilawra, Rohta Road, Meerut**.

Inspired by royal Rajasthani and contemporary Indian wedding aesthetics, featuring cream, ivory, champagne gold, peach, and royal maroon tones with Lord Ganesha's sacred blessings.

## 🚀 Getting Started

To run the project locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal) in your browser.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion v12) + HTML5 Canvas
- **Icons**: Lucide React
- **Audio**: Web Audio API Procedural Classical Indian Instrument Synthesizer
